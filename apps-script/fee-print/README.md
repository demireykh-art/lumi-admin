# 원내 가격표 인쇄 (Google 시트 Apps Script)

`루미의원 수가표 (원본)` 시트에서 원내 비치용 가격표를 A4로 뽑는다.
디자인은 홈페이지 `price.html`(functions/index.js `_buildPriceHtml`)과 같은 팔레트·서체.

## 설치 (한 번만)

1. 시트 열기 → **확장 프로그램 → Apps Script**
2. 왼쪽 `Code.gs` 내용을 지우고 이 폴더의 `Code.gs` 를 붙여 넣는다.
3. 왼쪽 **+ → HTML** 로 파일을 만들고 이름을 `Print` 로 한다(확장자 없이).
   이 폴더의 `Print.html` 내용을 붙여 넣는다.
4. 저장 → 시트 탭을 새로고침하면 메뉴에 **🖨 원내 출력물** 이 생긴다.
5. 처음 한 번은 권한 승인 창이 뜬다(이 시트 읽기 권한).

## 쓰는 법

**🖨 원내 출력물 → 가격표 인쇄 미리보기** → **🖨 인쇄**. 인쇄 창에서 "PDF로 저장"도 된다.
인쇄 버튼이 반응이 없으면 **새 창에서 열기**. 인쇄 창의 '머리글과 바닥글'은 끈다(날짜·URL이 찍힘).

- A4 한 장에 카테고리 하나. 짧고 맥락이 가까운 것은 한 장에 묶는다 — `Print.html` 의 `PAGE_GROUPS`
  (여드름 관리+레이저 / 스킨부스터+줄기세포 / 주름+볼륨 / 제모+케어·수액 / LUMI EVENT+VIP).
  여기 없는 카테고리는 한 장에 하나씩, 시트에 새 카테고리가 생기면 자동으로 따로 한 장.
- 글자는 장마다 18pt 에서 시작해 넘치면 줄이고, 한 단으로 13pt 아래가 되면 두 단으로 바꾼다
  (지금 데이터로 색소·돌출 질환이 두 단). 어떤 장도 다음 장으로 넘어가지 않는다.
- 장마다 아래에 하단 문구(원내 노출분)와 기준일이 들어간다.

## 노출 규칙

| 값 | 원내 출력물 | 홈페이지 |
| --- | --- | --- |
| 둘다 | ○ | ○ |
| 원내만 | ○ | × |
| 홈페이지만 | × | ○ |
| 숨김 | × | × |

- 줄의 노출이 **비어 있으면** 카테고리 탭 값을 따른다.
- 줄에 값이 있으면 **카테고리 ∩ 줄** — 둘 중 좁은 쪽이 이긴다.
  카테고리 `둘다` + 줄 `숨김` → 숨김. 카테고리 `숨김` → 줄 값과 상관없이 숨김.
  (줄 값으로 카테고리보다 **넓힐 수는 없다**: 카테고리 `원내만` + 줄 `둘다` → 원내만.)
- 시트의 '행 숨기기'(우클릭 → 행 숨기기)는 출력에 영향을 주지 않는다. 노출 열만 본다.
- 모르는 값(오타 등)은 숨김 처리하고 미리보기 상단에 ⚠로 알려 준다.

## 주의

  2026-10 폐지했고, 통합앱 홈의 **💵 수가표** 줄은 이 시트를 새 창으로 연다.
